LotDsp 項目の紐づけ

← アプリへ戻る

LotDsp の API が返す項目（staffTestBean.kei_CU など）が、画面のどの見出しなのかを、同じロットの値の一致で調べます。 出力は「項目 ↔ 見出し」だけで、値は含まれません（そのまま貼って見せられます）。

  1. 1

    画面を保存する

    LotDsp で調べたいタブを開き、右クリック →「名前を付けて保存」で HTML を保存します。タブごとに1つです。

  2. 2

    ロット違いも保存する

    同じタブを別のロットでもう1つ保存すると、偶然の一致が消えて、見出しが確定します。

  3. 3

    ここで選んで照合する

    保存した HTML をまとめて選びます。このアプリが同じロットの API を引いて、値を照らします。

    状態画面の見出し応答の項目（道すじ）いまの用途

    応答に入っている項目の一覧

    ロット番号で LotDsp の API を1回引き、応答に入っている項目をすべて（道すじ・型・形・空でない件数・このアプリが使っているか）一覧にします。 既定は形だけ（数字は 9・英字は a）で、値は含みません。何も覚えず、何も書き換えません。
